## 📄 Long Description

**SEOscoper** is a comprehensive, modern, and lightning-fast on-page SEO analyzer Chrome extension that helps SEO experts, technical webmasters, developers, and digital marketers audit critical on-page elements in real time with one click.

Analyze meta tags, heading structure (H1–H6), image alt text, embedded and self-hosted videos, internal and external links, broken links, nofollow directives, Open Graph, Twitter Cards, and JSON-LD schema markup instantly. Copy individual values, download full inventories, or export clean CSV and JSON reports to accelerate your technical SEO workflow.

### 🌟 Why SEO Specialists Choose SEOscoper:

⚡ **Instant Audit in Under 300 ms**
Built with pure vanilla JavaScript and CSS variables—no heavy frameworks. SEOscoper opens immediately and audits large pages without slowing down your browser.

🎯 **Overall On-Page SEO Score Ring**
Get a 0–100 calculated health score based on critical search ranking factors. The "Fix This First" prioritized checklist gives you actionable tips to quickly resolve technical on-page errors.

👁️ **Live On-Page Highlighter**
Click "Locate" on any heading, image, or link in the extension popup to smoothly scroll to and pulse-highlight it directly on the active webpage.

🔗 **Concurrent Link Status & Broken Link Checker**
Send asynchronous `HEAD`/`GET` requests with a concurrency limit of 5 to detect 200 OK, 301/302 redirects (with destination URLs), and 404 broken links without stalling your page.

📦 **Single & Batch Image ZIP Extractor**
Inspect natural vs. rendered dimensions, file formats (WebP, SVG, AVIF, JPG, PNG), alt text presence, and lazy loading. Download individual images or package all webpage media into a `.zip` archive with one click.

📐 **Indented Headings Hierarchy Tree**
Visualize full heading nesting from H1 through H6 in natural DOM order. Automatically detects missing H1s, multiple H1s, skipped heading levels, duplicate headings, and excessively long headings.

🧩 **Structured Data & Schema Markup Viewer**
Detect and parse JSON-LD (`application/ld+json`), Microdata, and RDFa with formatted syntax-highlighted blocks and copy shortcuts. Directly test any page using the Google Rich Results Test and Schema Markup Validator.

🌓 **Modern Dark & Light Mode**
Card-based modern dashboard with gentle shadows, accessible typography, tabular numerals, and automatic system theme detection.

🔒 **100% Client-Side Privacy Guarantee**
All analysis runs locally inside your browser. SEOscoper never collects, tracks, stores, or transmits your browsing data or page content.

### 🛠️ Key Features Summary:

- **Summary Tab**: Overall SEO Score (0-100), Meta Title (character count & SERP pixel width), Meta Description, Canonical URL verification, Robots meta tags (`noindex`, `nofollow`, `noarchive`), Googlebot directives, Viewport mobile responsiveness, Language, Charset, Author, Publisher, Word count, Page load time, Open Graph & Twitter Cards, and quick links to `/robots.txt` and `/sitemap.xml`.
- **Headers Tab**: H1–H6 counts, visual hierarchy tree with level indentation, warning diagnostic badges, character counts, click-to-highlight on webpage, and CSV/JSON export.
- **Images Tab**: Alt text status (missing vs. decorative empty alt), title attributes, natural dimensions, file formats, estimated file sizes, lazy-load detection, single image download, batch ZIP packaging, and preview popover.
- **Videos Tab**: Detects HTML5 `<video>`, YouTube, Vimeo, Dailymotion iframes, Open Graph video, and VideoObject schema. Includes built-in modal player and attributes inspector.
- **Links Tab**: Internal vs. external link audit, Dofollow vs. Nofollow, rel attributes (`sponsored`, `ugc`, `noopener`), empty anchor text alerts, live HTTP status checks (200, 301, 302, 404, 500, timeout), and on-page element highlighter.
- **Schema Tab**: Formatted JSON-LD viewer with syntax highlighting, Microdata and RDFa support, validation alerts, and single-click buttons for Google Rich Results Test & Schema.org Validator.
- **SEO Tools Tab**: Curated directory of 20+ top industry tools (SEMrush, Ahrefs, Moz, Screaming Frog, PageSpeed Insights, Google Search Console, Rank Math, Yoast SEO, Canva) and featured developer utilities at EasyPro Tools.
- **About Tab**: Version info, creator bio, direct email contact, social links, and Buy Me A Coffee support.
