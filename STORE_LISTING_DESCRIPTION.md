## Detailed Description (Paste directly into Chrome Developer Console):

SEOscoper is the ultimate free, privacy-first on-page SEO analyzer and audit extension for Google Chrome.

Whether you are an SEO specialist, web developer, content marketer, or site owner, SEOscoper gives you immediate, deep technical insight into any webpage's on-page SEO factors with a single click. Analyze metadata, extract live page keywords, calculate an algorithmic 100/100 SEO health score, inspect heading hierarchy (H1–H6), audit image alt tags with one-click bulk ZIP export, detect broken links, and validate structured schema markup—all rendered in a lightning-fast, modern interface with dark and light mode support.

100% Free. No subscriptions. No account required. 100% client-side execution with zero data collection.

━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 DEEP FEATURE BREAKDOWN ACROSS 9 TABS
━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 📋 Summary & Page Metadata
• Meta Title Tag: Character counter (30–60 chars) and Google SERP pixel width preview (~580px limit) with status badges.
• Meta Description: Character counter (70–160 chars) and snippet display viability check.
• Meta Keywords: Real-time extraction of <meta name="keywords"> with individual keyword pills and copy tools.
• Canonical URL: Compares declared canonical tag against active URL to catch self-canonical or cross-domain mismatches.
• Robots Directives: Highlights indexability tags including index, noindex, follow, nofollow, noarchive, and nosnippet.
• Googlebot Directives: Dedicated inspection of search bot directives.
• Technical Standards: HTML lang tag, UTF-8 character encoding, and mobile responsive viewport audit.
• Social Cards: Complete audit of Open Graph (og:title, og:image, og:url, og:type) and Twitter Cards.
• Hreflang Tags: Complete list of international and regional alternate language versions.
• Content Metrics: Total on-page word count and page navigation timing in milliseconds.
• Direct Server Diagnostics: One-click shortcuts to test /robots.txt and /sitemap.xml.

2. 🎯 Dedicated SEO Score (10-Factor Ranking Point Breakdown)
• Animated Circular Score Gauge (0–100): Visual health indicator color-coded for instant feedback (Green: Excellent, Amber: Needs Improvement, Red: Poor).
• 10 Evaluated Ranking Factors:
  1. Meta Title Tag (15 pts): Optimal length (30-60 chars) and SERP pixel width.
  2. Meta Description (15 pts): Optimal length for full snippet display.
  3. H1 Heading Structure (15 pts): Verifies exactly one clean H1 exists.
  4. Canonical Tag (10 pts): Confirms canonical presence and accuracy.
  5. Image Alt Coverage (10 pts): Audits percentage of images with descriptive alt text.
  6. Open Graph Social Meta (10 pts): Checks social title and preview card image.
  7. Language & Charset (10 pts): Validates HTML lang and UTF-8 declarations.
  8. Heading Hierarchy (5 pts): Checks for skipped heading levels (e.g. H1 jumping to H3).
  9. Mobile Viewport (5 pts): Confirms standard responsive viewport configuration.
  10. Search Indexability (5 pts): Verifies page is open to search engines without accidental noindex.
• Prioritized Action Plan: Issues ordered by ranking impact with actionable resolution guidance.

3. 📑 Heading Structure (H1–H6)
• Heading Counter Grid: Real-time totals for H1, H2, H3, H4, H5, and H6 tags.
• Structural Issue Alerts: Automatic detection of missing H1, multiple H1s, empty headings, skipped levels, and long headings (>70 chars).
• Full Heading Text: Natural word wrap with full text display—never cut off with ellipses.
• Visual Tree Representation: Indented heading tree showing DOM depth and hierarchy.
• Instant On-Page Locator: Click "Locate" to jump directly to and highlight any heading on the live page.
• Search & Filter: Search headings by text or filter by level (H1 through H6).
• Export Options: Copy all headings as formatted text, download CSV, or export JSON.

4. 🖼️ Images & Alt Text Audit
• Image Summary Metrics: Total images, with alt, missing alt, empty alt, with/without title attributes, lazy-loaded count, and estimated size.
• Visual Gallery Cards: Shows thumbnails, natural dimensions, file size, format badge (WebP, PNG, JPG, SVG), and alt text.
• 1-Click Bulk ZIP Export: Download every image on the page bundled into a single ZIP file.
• On-Page Scroll & Highlight: Locate any image on the live page instantly.
• Search & Format Filters: Filter by Missing Alt, Missing Title, Empty Alt, Lazy, or format.
• Export Data: Export complete image audit to CSV or JSON.

5. 🎬 Videos & Media Embeds
• Detection Counters: Total video elements, embedded players (YouTube, Vimeo, Dailymotion), and HTML5 <video> tags.
• Parameter Inspection: Source URLs, player dimensions, autoplay, controls, loop, and preload settings.
• Quick Links: Open video source files directly in a new tab.

6. 🔗 Internal & External Links Audit
• Link Counts: Total links, internal, external, dofollow, nofollow, sponsored, UGC, and empty anchor text.
• Built-In HTTP Status Checker: Test links directly from the extension to identify 404 dead links and redirects.
• Link Breakdown Cards: Displays anchor text, destination URL, internal/external badges, and follow/nofollow status.
• Interactive Search & Filter: Filter by Internal, External, Dofollow, Nofollow, Broken, Redirected, or Missing Anchor Text.
• Data Export: Export complete link inventory to CSV or JSON.

7. 🏷️ Schema Markup & Structured Data
• Detected Schema Types: Displays recognized types (WebSite, Article, Product, Organization, FAQPage, BreadcrumbList, LocalBusiness, etc.).
• JSON-LD & Microdata Viewer: Formats and syntax-highlights structured data blocks with copy utilities.
• 1-Click Validator Shortcuts: Direct links to the official Google Rich Results Test and Schema Markup Validator pre-loaded with current URL.

8. 🛠️ Curated SEO Tools Suite
• Featured Integration: EasyPro Tools suite for developers and digital marketers.
• Built-in Quick Launchers: Google PageSpeed Insights, Mobile-Friendly Test, DNS & WHOIS lookups, Wayback Machine archives, and SSL checkers.
